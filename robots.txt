#  How this file is read
#  ─────────────────────
#  A crawler obeys only the most specific group that names it and ignores
#  the rest. Giving a crawler its own "Allow: /" group therefore cancels
#  every Disallow below for that crawler. So every search and AI crawler
#  is named in ONE shared group with the same rules. To welcome a new
#  crawler, add a "User-agent:" line to that group; never give it a group
#  of its own.
#
#  Crawling is not indexing. Which pages appear in search is decided by
#  each page's own <meta name="robots">: app screens and empty location
#  pages say noindex. Pages that say noindex stay crawlable here, because
#  a crawler has to fetch a page to see that it should be dropped.
#
#  Tracking links (?utm_…, ?ref=…) are deliberately NOT blocked. Shared
#  and referral links carry them, and every page declares its canonical
#  URL, so search engines fold those links into the real page instead of
#  losing them.
